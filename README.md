# EduCrew AI

Autonomous Multi-Agent AI Teacher Assistant & Intelligent School Timetable Generator powered by **CrewAI**, **Streamlit**, and **Google Gemini** (`gemini-1.5-flash`).

## Key Capabilities
1. **Multi-Agent Collaborative Lesson Designer**:
   - Curriculum & Lesson Designer: Structured 45-minute lesson objectives.
   - Assessment Specialist: Bloom's taxonomy quizzes, keys, and rubrics.
   - Differentiated Learning Coach: Remedial and enrichment adaptations.
2. **Automated School Timetable Engine**:
   - Monday to Thursday & Saturday: 8 periods/day.
   - Friday: 5 periods.
   - Constraint: The **Farm Master** is automatically assigned Period 1 across all 6 days.

## Setup & Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
